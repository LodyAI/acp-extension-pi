## 摘要

适配器将 Pi 固定升级到 1.3.0，保留原生执行、会话身份、扩展显式选择和 ACP 管理的 MCP 配置。
由于 `--no-extensions` 也会禁用内置扩展，父子进程都显式加载 codemode。
已处理的输入无需等待模型结束事件；todo 快照和有限的嵌套调用元数据可以从原生会话中恢复。
本改动准备适配器发布；已安装的 Lody Provider 仍需单独构建并校验托管运行时后才能获得更新。

## 决定

继续使用现有 RPC 适配器和 Pi 原生 codemode，不增加执行器、版本探测、轮询窗口或后台调度。
外部运行时覆盖需要实现相同的 1.3 契约。Pi 内置 MCP 保持关闭，服务器选择仍由 ACP 负责。

Pi 将嵌套工具记录为外层结果的元数据，不保存完整的嵌套输出。
回放使用其中的调用 id、参数和状态，不推测缺失结果。
打包的 todo 扩展把现有快照附在 codemode 结果中，恢复时同时读取直接 todo 结果和外层结果，不增加独立存储。
与提交输入脱离的扩展后台工作仍不受支持。

MCP 工具的输出 schema 从官方 SDK 的文本、图片结果契约派生。
原有模型可见内容和错误处理保留；codemode 额外收到经过 JSON 验证的结构化结果，
让 `image()` 能把图片块转交模型，不启用内置 MCP 自动发现。
